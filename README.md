# Swift AI 1.0

A rule-based chatbot with a rude personality — no external APIs, 
pure logic and pattern matching.

Built as a foundation for understanding how chatbots work 
before integrating LLMs.

## Run Locally

```bash
git clone https://github.com/SwiftDG/swift-ai-1.0.git
cd swift-ai-1.0
node index.js
```

## About

Swift AI 1.0 is the first iteration of the Swift AI project. 
It uses rule-based pattern matching to respond to user input — 
no machine learning, no API calls, just logic.

*Built by [David Gilbert](https://github.com/SwiftDG)*
